# Sales Data Analysis Using Microsoft Excel

## About the Project
This is a beginner-level Data Analyst project focused on analysing retail sales data using Microsoft Excel.

## Project Objectives
- Analyse total sales and profit.
- Identify top-performing products.
- Compare regional sales.
- Understand monthly sales trends.
- Analyse customer segments.
- Generate business insights.

## Tools Used
- Microsoft Excel
- Excel Formulas
- PivotTables
- PivotCharts
- Data Cleaning
- Data Visualization

## Dataset
Sample Superstore Dataset.

Source: https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

## Project Workflow
1. Data collection
2. Data understanding
3. Data cleaning
4. Data transformation
5. Exploratory data analysis
6. PivotTable analysis
7. Dashboard creation
8. Business recommendations

## Analysis Questions
- Which region has the highest sales?
- Which category generates the highest profit?
- Which products perform best?
- Which month has the highest revenue?
- Which customer segment contributes the most sales?
